🏠 House Price Prediction using Machine Learning in R
📌 Project Overview

This project predicts house prices using Machine Learning algorithms in R.
The dataset is analyzed using Exploratory Data Analysis (EDA) and multiple visualizations to understand the relationship between different house features and price.

The project implements Linear Regression and Random Forest models to predict house prices and compares their performance using evaluation metrics.

📊 Dataset

The dataset contains various features that influence house prices, including:

Area

Bedrooms

Bathrooms

Stories

Parking

Air Conditioning

Furnishing Status

Preferred Area

Target Variable:

Price

EDA was performed to understand the dataset and identify relationships between features and house prices.

🤖 Machine Learning Models

The following models were implemented:

1️⃣ Linear Regression

Baseline model for predicting house prices

Helps understand linear relationships between features

2️⃣ Random Forest

Ensemble learning algorithm

Captures complex relationships between variables

Provides feature importance analysis

📈 Model Evaluation

Models were evaluated using:

RMSE (Root Mean Squared Error)

Residual Error Analysis

Prediction Error Distribution

Actual vs Predicted Price Plot

Random Forest performed better due to its ability to model nonlinear relationships.
